# Methods of Thinking

A self-guided field course for clearer problems, stronger evidence, better choices, and faster learning.

The complete course lives in [`index.html`](./index.html). It includes:

- 14 thinking stages
- 84 guided lessons
- 879 searchable methods
- 137 practice challenges
- 164 inline diagrams with a full-size viewer

Open the published site and choose **Begin the course**. Progress, notes, solved challenges, bookmarks, and the last open lesson stay in the browser. No account or server is required.

The site is a single standalone HTML file. It has no external assets, build step, or runtime dependency.
